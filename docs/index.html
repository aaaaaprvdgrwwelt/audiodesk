AudioDesk

Ein Dateimanager für Musik und Hörbücher: sichten, hören, Metadaten holen, umbenennen. Läuft mit einer Wiedergabeleiste am unteren Fensterrand, nicht mit einem eigenen Fenster pro Datei.

Auf GitHub ansehen Installation Metadaten-Quellen
Status: nutzbar. Entwickelt und getestet unter Linux. Windows und macOS sollten laufen (reines Qt/Python), sind aber nicht manuell getestet — die automatisierte Testsuite läuft dort in der CI.

Was es kann

Musik (Album/Track) und Hörbücher (Buch/Kapitel) in einer gemeinsamen Bibliothek, Oberfläche auf Deutsch und Englisch.

Wiedergabeleiste

Bleibt dauerhaft am unteren Fensterrand offen, mit Warteschlange, Zufallswiedergabe und Wiederholen (aus/alle/aktueller Titel).

Kapitelmarken bei M4B

Eingebettete Nero-Kapitelmarken werden ausgelesen und erscheinen als Sprungliste — kein durchgehendes Abspielen mehr ohne Struktur.

Musik- und Hörbuch-Ordner getrennt

Eine automatische Erkennung anhand der Datei allein wäre unzuverlässig — der Ordner legt fest, ob etwas als Track oder Kapitel geführt wird.

Vier Metadaten-Quellen

MusicBrainz, Discogs und Last.fm für Musik, Apples iTunes-Suche als einzige eingebaute Hörbuch-Quelle — sauber quellenweise getrennt.

Lautstärke gemerkt

Bleibt über einen Neustart hinweg erhalten — kein erneutes Einstellen bei jedem Programmstart.

Gezielt rescannen

Nur ein einzelnes Album oder Hörbuch neu einlesen, statt jedes Mal die ganze Bibliothek zu durchsuchen.

Installation

Fertige Pakete für Windows/macOS unter Releases — unsigniert, deshalb beim ersten Start je einmal „Trotzdem ausführen“ (Windows) bzw. Rechtsklick → Öffnen (macOS) bestätigen. Aus dem Quelltext (Linux und alle anderen) reicht Python 3.10 oder neuer:

git clone https://github.com/aaaaaprvdgrwwelt/deskkit.git
git clone https://github.com/aaaaaprvdgrwwelt/audiodesk.git
cd audiodesk
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

Unter Linux zusätzlich libpulse0 für die Wiedergabe über QtMultimedia.

Starten

./audiodesk.sh              # oder: .venv/bin/python -m audiodesk
./install-desktop.sh        # Eintrag im Anwendungsmenü anlegen (Linux)

Metadaten-Quellen

Alle vier optional, einzeln unter Einstellungen → Quellen abschaltbar. API-Keys landen im System-Schlüsselbund statt im Klartext.

QuelleFürKey
MusicBrainzMusiknein, empfohlen
DiscogsMusik, Zweitquelleja, kostenlos
Last.fmMusik, Zweitquelleja, kostenlos
iTunesHörbücher, einzige eingebaute Quellenein
Bewusst nicht eingebaut: Audible. Keine öffentliche API — ein Zugriff liefe nur über Scraping der Webseite gegen deren Nutzungsbedingungen, auch nicht über importierte Skripte anderer Tools.

Umbenennen-Vorlagen

Getrennt für Musik und Hörbücher, frei einstellbar unter Einstellungen → Umbenennen.

Musik:      {artist}/{album}/{track_number:02} - {title}{ext}
Hörbücher:  {book_title}/{chapter:03} - {title}{ext}
